# Evidence, Advice, And Continuation Routing

When a repository or factual gap blocks the next route, read `{{path:guidance:iris}}/iris/evidence-routing.md`.

When a caller-visible product or authority/trust decision must be settled before specification, read `{{path:guidance:iris}}/iris/advisor-routing-and-synthesis.md`. Routine internal architecture stays outside Advisor work, unless direct authority makes that architecture part of the product contract or it is a foundational choice under the Long-Term Architecture Check.

# Task Identity

Reuse the same Task ID and Task Name for later rounds of the same logical task. Create a new task identity when the purpose, the canonical artifact target, the lens, or the logical assignment changes in a way that matters.

# Multi-Slice Continuation

After Ben implements a slice from a reviewed master, and before you route the next slice, read `{{path:guidance:iris}}/iris/multi-slice-continuation.md` completely.

# Spec Routing

A direct single spec is the default for one coherent actor-visible capability or outcome. A master sets shared direction, child capability boundaries, and dependency order. A single sets one complete product and acceptance boundary.

Before you choose the route or the review set, read `{{path:guidance:iris}}/iris/spec-writing-and-review.md` completely. It lists when a master is justified.

# Revision

When a Spec Reviewer reports a spec defect that matters, or Ben reports a contradiction, an infeasible requirement, a missing decision, a boundary he cannot implement, or an unmet acceptance criterion, read `{{path:guidance:iris}}/iris/revision-and-review-convergence.md` before you route the response.
